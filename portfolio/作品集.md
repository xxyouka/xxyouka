# 作品集

**目录**：`portfolio`　·　**形态**：纯静态单页（归档，不再部署）　·　**线上**：只保留根站 <https://xxyouka.github.io/>　·　**最近提交**：2026-11-11

## 内容

- **封面故事**：校园猫猫、pet-id
- **作品索引**：果智瞳、software-test-helper、BitClock、danmu-player
- 荣誉、关于、更多实验

## 技术

纯 HTML / CSS / 原生 JavaScript。没有框架、没有外部字体、没有统计脚本，静态托管即可运行。

- 亮 / 暗色跟随系统，可手动切换并记忆
- 响应式，320px 起可读；顶栏吸顶
- `prefers-reduced-motion` 下关闭动效
- 自绘 SVG 图标与封面，内容截图统一为 WebP
- canonical、Open Graph / Twitter Card、JSON-LD、`sitemap.xml`、`robots.txt`
- 页脚提供回主站 <https://xxyouka.github.io/> 的入口

## 怎么跑

在仓库根目录：

```bash
./scripts/preview.sh 8766
```

打开 <http://127.0.0.1:8766/portfolio/>，或直接双击 `index.html`。
