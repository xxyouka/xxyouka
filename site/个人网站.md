# 个人网站

> xx · xxyouka 的个人作品集主站：杂志编辑风、中英双语、纯静态，部署在 GitHub Pages 根站。

**目录**：`xxyouka.github.io`　·　**形态**：纯静态站点（无构建）　·　**线上**：<https://xxyouka.github.io/>　·　**最近提交**：2026-11-02

## 线上是什么样

- 首屏以 **Vol.01 封面**形式展示真实项目手机截图
- **四个精选项目**：校园猫猫、pet-id、双人食刻、第九条命；分类筛选、案例详情、图片切换与大图、键盘关闭、手机导航、阅读进度、回到顶部
- 案例详情含 YEAR / ROLE / STACK 与结果、过程、取舍、数据证据
- 桌面端项目卡有指针跟随光斑和像素溶解预览；触屏与「减少动态效果」下自动关闭
- 三条鲨鱼与一条锦鲤在网页空间自由游动；标签页隐藏时停止动画计算
- 分享卡片 `assets/og-cover-20261102c.png`（1200×630）与 canonical / og / Twitter Card 均指向正式域名

## 本地预览

```bash
python -m http.server 8766 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8766/>；Windows 也可以运行 `start-preview.ps1`。页面无构建步骤，改完刷新即可。
